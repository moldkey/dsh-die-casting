壁厚/脱模角/锁模力校核，常见缺陷对策。

## 安装

    dsh plugin --profile web add github:moldkey/dsh-die-casting

## 工具

- `die_casting_dfm`：DFM 与吨位估算
- `die_casting_defect`：缺陷排查

更多工具：https://deepseekbase.com/zh/tools/
